# Maryland concise review questions

1. **Route definitions:** Both the long and short paths are now understood to be
genuine driven routes. What should each be called, during which laps/time ranges
was each active, and which route should be nominal for each analysis?

2. **Elevation provenance:** Are the McMaster and ÉTS/Strava elevations raw device
measurements, barometric altitude, or map-corrected Strava elevation? Is the raw
FIT altitude available so shared map elevation is not mistaken for independent
agreement?

3. **Obstacle inventory:** For each repeated hump section, what are the agreed
count, approximate height, length, spacing and total section extent? The detailed
notes explicitly contain a six-whoop sequence, a three-bump section and a
four-large-bump section, but the comparison workbook values were not included in
the reviewed files.

4. **Coordinate gaps:** Can missing or intentionally shared coordinates be marked
explicitly? Current examples include a right-hairpin entry and exit with the same
coordinate, a later right-hairpin exit with no coordinate, and several combined
hill/turn/whoop/berm observations at one location.

5. **Source authority:** For disagreements, should the timestamped video notes
control event order, raw telemetry control path/elevation, and the workbook remain
an independent checklist rather than an automatic override?
